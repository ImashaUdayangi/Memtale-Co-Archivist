## Dataset Description

This dataset consists of publicly available autobiographical oral-history transcripts curated from StoryCorps.

All stories are first-person life narratives describing personal experiences such as family relationships, work, migration, loss, and aging.

The dataset was manually curated to ensure narrative coherence and emotional richness. Only publicly accessible transcripts were included. No personal identifying metadata beyond what is already public was added.

This dataset is used exclusively for research and evaluation purposes.
